# تَكَلَّم — التأهيل التخاطبي

برنامج تفاعلي عربي للأطفال (مفردات، تمييز سمعي، جمل، ذاكرة، علاج اللدغة).

## 1) رفع المشروع على GitHub
1. أنشئ مستودعًا جديدًا (New repository) باسم `takallam`.
2. ارفع كل محتويات هذا المجلد (اسحبها إلى صفحة المستودع: Add file ← Upload files).
3. انتظر دقائق، ثم افتح تبويب **Actions**.

## 2) الحصول على تطبيق الأندرويد (APK)
- في Actions افتح آخر تشغيل لـ **Build Android APK** ← أسفل الصفحة **Artifacts** ← حمّل `Takallam-APK`.
- فك الضغط، وانقل `app-debug.apk` إلى الموبايل، وثبّته (اسمح بالتثبيت من مصدر غير معروف عند الطلب).
- عند أول تسجيل صوت سيطلب التطبيق إذن الميكروفون: اضغط **السماح**.

## 3) الموقع (يعمل عليه الميكروفون أيضًا)
- Settings ← Pages ← Source: **GitHub Actions**.
- بعد التشغيل الناجح لـ **Deploy website** يظهر الرابط في نفس الصفحة، شكله: `https://USERNAME.github.io/takallam/`.

## تعديل البرنامج
كل البرنامج في ملف واحد: `www/index.html`. أي تعديل ثم رفعه يبني APK والموقع من جديد تلقائيًا.

## ملاحظات
- صوت النطق يعتمد على صوت عربي مثبّت في الجهاز (Google Text-to-Speech ← العربية).
- زر «تحقق تلقائي» غير متاح داخل التطبيق؛ تسجيل الصوت وإعادته للطفل يعمل، والتقييم يدوي.
